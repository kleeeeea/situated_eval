01 / THE PROBLEM

Good answers.
Not necessarily
good teaching.

Educational LLM benchmarks have become increasingly sophisticated. Yet most still examine a single input–output episode: Is the response correct, clear, or complete?

Real teaching is different. The value of a hint depends on who receives it, what came before, and what happens next. A perfectly correct explanation might still fail to support learning.

↗

We argue for a shift in the evaluation target: from output quality to pedagogical action in context.

THE DOMINANT PARADIGM →

Task-based evaluation

One prompt. One response. One score.

INPUT Explain this concept.
MODEL Accurate explanation.
✓ Correct answer

THE PROPOSED DIRECTION ↗

Situated evaluation

Context. Action. Subsequent evidence.

CONTEXT Learner history + goals
ACTION Adaptive teaching response
FOLLOW-UP Revision + transfer
↗ Pedagogical value in context

Examines quality, fit, and learning progression

02 / THE FRAMEWORK

Three layers.
One richer picture.

Situated benchmarks should distinguish what a model says, whether it fits the teaching situation, and what learning evidence follows.

SELECTED / LAYER 01

Task Quality

The essential foundation: reliable educational content, judged for correctness and clarity. Situated evaluation builds on this layer rather than replacing it.

These layers are organizing principles, not a fixed universal scoring scale. Appropriate metrics and evidence depend on the teaching task.
